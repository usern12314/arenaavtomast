# Как собрать установочный .exe «Автомастерская»

Сборка делается на вашем компьютере с Windows один раз — дальше установщик
можно носить на флешку и ставить куда угодно.

## Шаг 0. Установить инструменты

1. **Node.js LTS** — скачать с https://nodejs.org (кнопка LTS), установить со всеми галочками по умолчанию.
2. Открыть **терминал** (Win + R → `cmd` → Enter) и проверить:

```
node -v
npm -v
```

Обе команды должны показать версии.

## Шаг 1. Подготовить проект

В терминале перейти в папку проекта и выполнить:

```
cd путь\к\папке\проекта
npm install
npm install -D electron electron-builder
```

## Шаг 2. Добавить 6 строк в package.json

Открыть `package.json` в любом редакторе (Notepad++ / VS Code) и:

1. Рядом со строкой `"version"` добавить:

```json
"main": "electron/main.cjs",
```

2. В блок `"scripts"` добавить две строки:

```json
"electron": "electron .",
"dist:win": "npm run build && electron-builder --win nsis",
```

Должно получиться примерно так:

```json
{
  "name": "react-vite-tailwind",
  "private": true,
  "version": "1.0.0",
  "main": "electron/main.cjs",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "electron": "electron .",
    "dist:win": "npm run build && electron-builder --win nsis"
  }
}
```

## Шаг 3. Запустить приложение в окне (проверка)

```
npm run build
npm run electron
```

Откроется окно «Автомастерская» — это уже почти готовый exe, просто без установщика.

## Шаг 4. Собрать установщик

```
npm run dist:win
```

Первая сборка длинная (electron-builder скачивает Electron и NSIS, ~150 МБ).
Готовый файл появится здесь:

```
release\Avtomasterskaya-Setup-1.0.0.exe
```

Вот этот файл и есть установщик. Ставится как обычная программа:
ярлык на рабочем столе и в меню «Пуск».

## Где хранятся данные

Данные хранятся внутри приложения (в профиле Windows пользователя) —
как раньше `avtomasterskaya.db` рядом с программой, только автоматически.

Кнопка **«Скачать»** (резервная копия) в десктопной версии открывает
привычный диалог «Сохранить как» — можно сохранять прямо на флешку.

**Перенос данных из браузерной версии в exe:**
в браузере нажать «Скачать» (получите JSON) → в exe нажать «Загрузить» → выбрать этот файл.

## Частые вопросы

- **Windows SmartScreen ругается при установке** — это нормально для неподписанных
  программ: «Подробнее» → «Всё равно запустить». Чтобы предупреждения не было
  совсем, нужен платный сертификат подписи кода (~$200/год), для своей мастерской не нужен.
- **Антивирус удалил файл** — добавьте папку проекта в исключения на время сборки.
- **Хочу свою иконку** — положите файл `icon.ico` (256×256) в папку `build\` рядом
  с проектом, electron-builder подхватит сам.
- **Версия в имени файла** — меняется полем `"version"` в package.json.

## Альтернатива: Tauri (exe ~10 МБ вместо ~200 МБ)

Если размер критичен: https://tauri.app — потребуется дополнительно
установить Rust (https://rustup.rs). Команды аналогичные:
`npm i -D @tauri-apps/cli` → `npx tauri init` → `npx tauri build`,
установщик появится в `src-tauri/target/release/bundle/`.
